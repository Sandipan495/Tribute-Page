# Tribute Page – Dr. APJ Abdul Kalam

A simple **tribute webpage** dedicated to Dr. APJ Abdul Kalam, the "Missile Man of India".  
This project is built using **HTML** and **CSS** to practice web development basics like layout, styling, and responsive design.

---

## 📌 Features
- Profile image of Dr. APJ Abdul Kalam
- Life journey including **Education** and **Career as Scientist**
- Background image with styled sections
- Clean typography and layout
- External reference link to Wikipedia

---

## 🖥️ Technologies Used
- **HTML5** for structuring the webpage  
- **CSS3** for styling and layout
